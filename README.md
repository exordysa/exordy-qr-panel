# EXORDY QR PANEL · interfaz

Interfaz del panel privado EXORDY QR PANEL (v1.0.0) de Exordy S.A. **Este repositorio no contiene datos ni claves**:
el panel se muestra dentro de una página privada de www.exordy.com (con contraseña), y todos los datos viajan por esa
página hacia el backend de Wix, que exige la clave de acceso del panel en cada operación. Abierto fuera de Wix, el
panel no carga nada.

Publicado con GitHub Pages desde la rama `main`.
